    GenAd Studio: Agentic Short-Video Advertising Lab

    Project Case 05 / Generative Media

    一个面向短视频广告生成的多智能体研究实验室，模拟从受众洞察、脚本分镜、文生视频提示词到视觉语言模型评审的创意生产链路。

    GitHub Repo Selected Work
    DomainGenerative Media
    MethodsMultimodal LLM + VLM Judge
    OutputCreative Workflow + Review Gate
    Strategic Question

    生成式广告如何既提升创意效率，又不牺牲品牌安全？

    项目把生成模型放进明确流程中：AI 负责扩展创意可能性、生成脚本和分镜候选，人类保留方向选择和最终判断，质量评审层负责降低风险。

    Decision Value

    把创意生产变成可复盘的实验系统。

    每个广告变体都保留受众假设、创意钩子、视觉风格、品牌安全检查和 A/B 学习记录，让创意不再只是灵感，而是可以沉淀的决策资产。

    Workflow

    Agentic Creative Operating System

    1. Insight由受众洞察 Agent 梳理痛点、动机、场景和信息触发点。
    2. Plan脚本与分镜 Agent 生成钩子、叙事结构、镜头顺序和提示词。
    3. Generate文生视频工作流生成候选素材，并保留风格约束。
    4. ReviewVLM Judge 检查品牌安全、画面一致性、事实表达和投放适配。
