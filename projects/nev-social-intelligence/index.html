    NEV Social Intelligence & Topic Discovery

    Project Case 04 / NLP

    一个围绕新能源汽车公共讨论的社交智能案例，用主题发现、语义聚类和情感计算识别消费者关注点的演化，把舆情噪声整理成可解释的市场洞察。

    GitHub Repo Selected Work
    DomainConsumer Intelligence
    MethodsTopic Modeling + Embeddings
    OutputNarrative Map + Research Brief
    Strategic Question

    如何区分长期消费者关切和短期舆论噪声？

    项目从公开语料中提取主题簇、情感变化和关键叙事路径，关注“讨论为什么发生变化”，而不仅是统计某个关键词出现了多少次。

    Decision Value

    让公众态度变成产品、品牌和政策分析的输入。

    通过把电池安全、补能便利、智能座舱、辅助驾驶、保值率和品牌信任等议题结构化，项目能支持市场研究、竞品观察和弱信号预警。

    Workflow

    Public Discourse Intelligence Chain

    1. Collect使用公开文本作为研究语料，并在入口处去除身份相关信息。
    2. Represent通过清洗、分词、嵌入和去重形成语义空间。
    3. Discover聚类并标注主题，观察议题热度和表达方式如何变化。
    4. Interpret把主题、情感和代表证据整理为研究简报。
