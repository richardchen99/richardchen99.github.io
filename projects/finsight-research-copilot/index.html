    FinSight: Evidence-Grounded Research Copilot

    Project Case 06 / LLM × Finance

    一个面向金融研究的证据约束型 Copilot 原型，把公告解析、跨文档检索、公司对比、事实核验和研究备忘录生成连接为可审计的分析工作流。

    GitHub Repo Selected Work
    DomainFinancial Research
    MethodsGraphRAG + Tool-use Agents
    OutputSource Cards + Research Memo
    Strategic Question

    金融研究 Copilot 如何降低幻觉并保持可追溯？

    项目将 LLM 限定在“带证据工作的研究助手”角色中。每个观点都需要关联公开文档来源、引用片段和不确定性说明，不能把没有证据的推断包装成确定结论。

    Decision Value

    让研究过程从阅读加速走向证据管理。

    FinSight 不是自动给出投资建议，而是帮助研究者更快地组织材料、发现矛盾、比较公司，并形成可以继续人工审阅的研究备忘录。

    Workflow

    Evidence-Grounded Analyst Loop

    1. Parse解析公告、年报、纪要和公开材料，形成可检索证据库。
    2. Retrieve围绕研究问题检索来源片段，并生成可点击的 source card。
    3. Verify检查观点是否被来源支持，标记矛盾、缺口和不确定性。
    4. Compose生成包含证据、反方观点、风险和后续问题的研究备忘录。
