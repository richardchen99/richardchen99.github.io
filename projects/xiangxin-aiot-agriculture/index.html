    Xiangxin AIoT Agriculture Platform

    Project Case 03 / AIoT

    一个面向智慧农业的 AIoT 平台原型案例，融合边缘感知、作物视觉识别和农业知识服务，让田间状态从“经验感知”变成“可观察、可解释、可执行”的运营信号。

    GitHub Repo Selected Work
    DomainSmart Agriculture
    MethodsComputer Vision + Edge AI
    OutputOperations Board + Knowledge Service
    Strategic Question

    如何让农业现场数据真正进入日常经营决策？

    项目把传感器、图像和农事知识连接成一个可执行流程：系统先识别异常和作物状态，再把结论解释为风险原因、建议动作和待确认事项。

    Decision Value

    从“智能识别”走向“经营协同”。

    项目重点不是单个模型，而是完整服务闭环：边缘采集、异常判断、知识解释、工单提醒和人工复核共同组成更可靠的智慧农业工作台。

    Workflow

    AIoT Field Operating Loop

    1. Sense采集土壤、光照、温湿度和作物图像，建立低侵扰的现场状态记录。
    2. Detect通过边缘模型识别作物长势、疑似病虫害、设备异常和环境波动。
    3. Explain使用农业知识服务解释风险原因，并给出可理解的农事建议。
    4. Operate把提醒转为工单、复核和操作记录，形成可追踪的经营闭环。
